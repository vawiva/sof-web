Soldier of Fortune

Raven Software, 2000 · browser port using the openMERC engine (WebAssembly)

Your game files stay on this device

This page plays the game from your own copy of Soldier of Fortune. Your files are read locally by this browser tab; they are never uploaded. Only the engine itself is downloaded from this site.

Tested edition: . Other 1.07f installations may work but are marked unverified.

    Choose your game folder

    Select the installation folder (for example Soldier of Fortune) or its base folder. The files pak0.pak, pak1.pak, pak2.pak, pak3.pak and gs.pak are needed (about 785 MB).

    …or drop the folder here

    Disc images (ISO/BIN/CUE), installers and archives are not read directly: install the game first. A browser's file dialog may need a mouse, keyboard or touch; once files are chosen, everything else works with a controller.

    Checking files…

    Ready

    The game starts with its original start-up and main menu and fills this browser window at its original 4:3 shape (black bars where the window is wider or taller). Load, save, settings and quitting are in the game's own menu (Esc). Quit in the game's main menu stores your settings and saves and returns to this page.

      Controls

      Keyboard and mouse (game defaults)
      Controller

      Left stick moves, right stick looks. Start opens the game menu.

      Touch

      Left side: drag to move (push fully to run). Right side: drag to look, tap to click menu items. On-screen buttons cover firing, jumping, crouching, using, reloading, weapons, items, leaning, objectives and the menu. Size, opacity and a left-handed layout can be changed below.

      Browser settings

      Tools of this web page, not of the game. The game's own saves are made and loaded in its menus; this browser keeps them, together with its settings, until you delete them here. Export makes a backup file that another browser can import.
