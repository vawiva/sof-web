Install the app to play on this device

On phones and tablets the game runs as an app from your Home Screen (full screen, no browser bars). This page stays available for setup and help.

  1. Open this page in Safari.
  2. Tap Share (the square with an arrow) → Add to Home Screen; keep Open as Web App on if it is offered → Add.
  3. Open Soldier of Fortune Web from its Home Screen icon.
  4. Continue setup and press Play there.

Recommended: the installed app has the whole screen. You can also play in this browser tab.

  1. Tap Install app above, or open the browser menu (⋮) → Install app / Add to Home screen.
  2. Open Soldier of Fortune Web from its Home Screen icon.
  3. Continue setup and press Play there.

The installed app keeps its own settings and saves: they are not shared with this browser tab. To take saves along, use Export here and Import in the app (Saves and storage).

The last game session did not end normally

Your saves are kept up to the last automatic store. A report of the session's last moments is kept on this device only (access keys removed).

    Multiplayer
    
        
    Checking…
    
        
    Joining happens in the game's own menu: Multiplayer → Join → Refresh lists the servers this PC
          forwards to. There is no internet server list, and this page cannot host a server for other devices.
    
      
    
      
    
        
    Saves and storage
    
        
    …
    
        
    The game saves and loads in its own menu; this browser keeps those saves and the game's
          settings. Export makes a backup file another browser can import. Nothing is synchronised between devices.
    
        
    
          
          
          
          
        
    
      
    
    
    

    
    
      
    Settings
    
      
    Settings of this page, kept in this browser; they apply the next time the game starts. The
        game's own options (keys, sound, video) are in its menu.
    

      
    Display
        
    
          
          
          
    Widescreen shows more at the sides; menus, the HUD's proportions and cinematics keep the
            original 4:3 framing. The frame rate changes only how often a picture is drawn, not the game's speed.
            
    
        
    
      
    

      
    Controls: input mode and touch
        
    
          
          
          
          
          
          
          
          
          
          
          
          
          
    Look speed is degrees of turn per pixel of finger travel: the same swipe turns the same
            amount at any resolution, picture shape or frame rate. Look follows the finger directly, without
            acceleration or smoothing.
    
          
        
    
      
    

      
    Controller
        
    
          
          
          
          
          
          
          
          
    Look speed is degrees per second at full deflection (no hidden boost unless Turn boost is on);
            the response curve sets how much of it partial deflections give. Left stick moves, right stick looks; the
            buttons are listed under Help.

    Advanced
        
    
          
        
    
      
    
    
    

    
    
      
    Help
    
      
    Keyboard and mouse (game defaults)
    
      
    Controller
        
    Left stick moves, right stick looks. Start opens the game menu.
    
      
    Touch
        
    Left thumb: drag anywhere on the left half to move; push fully to run. Right side: drag to look, lift to stop.
          Buttons: Fire, Jump, Crouch, Alt fire, Use, Reload, weapons; on the left Menu, objectives, lean and items.
          In the game's menus, tap items directly. Mobile play is landscape only.
    
      
    Play on a phone
        
    Let your PC host the game files: run the LAN host on the PC (see the project's LAN guide), open the tester
          link it prints on the phone and accept its certificate. The phone then shows the PC's game data as ready;
          nothing is copied to the phone. Controllers need this HTTPS link: browsers hide controllers on plain
          http addresses. To play without the PC later, use Download and keep the game from my PC
          once.
    
      
    Installers and disc images
        
    Under Keep the game on this device → Import game files or disc image… you can choose:
    
        
      
          
    • the GOG installer setup_soldier_of_fortune_1.07f_hotfix_(54919).exe (one file, Inno Setup
            5.6.2): it is read like an archive, nothing of it runs;
      • 
          
    • an .iso image of the 2001 Platinum CD: its InstallShield set is read;
      • 
          
    • or the five archives pak0.pak–pak3.pak and gs.pak.
      • 
        
    
        
    Only the five archives are kept (about 785 MB, plus temporary use while unpacking); every
          one is checked against the installer's own checksum. Other installers (other Inno Setup versions, installers with
          separate .bin files), BIN/CUE images and multi-disc sets are not supported.
